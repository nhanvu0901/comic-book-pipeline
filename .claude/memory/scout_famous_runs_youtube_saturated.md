# Famous acclaimed single-issue Marvel runs are Comicstorian-saturated (2026-07-03)

When hunting "best single issue ever" lists for step-2e (self-contained issue inside an
ongoing/event), the MOST acclaimed/famous single issues are almost always already narrated
in full by Comicstorian/Comics Explained — fame is exactly what gets a story covered.
Confirmed HAS_NARRATION on this pattern:
- Immortal Hulk (2018) #1 ("Bruce shot at a gas station, Hulk rises at night") — Comicstorian
  did a full 50-issue "Complete Story" multi-part series (PT1 = exactly this issue's content)
  + Comics Explained "The God Hulk" full story. The MORE acclaimed/famous the run, the more
  certain it has multi-part Comicstorian coverage — don't waste a verify call assuming "it's
  just issue #1, maybe it's too small to be covered."
- Captain America: Steve Rogers (2016) #1 "Hail Hydra" reveal — Comicstorian "Secret Empire
  Full Story" covers it; also fails structure gate (#1 of a #1-6 saga anyway).
- Devil's Reign: Moon Knight (2022) #1 — Comicstorian's Daredevil/Devil's Reign character
  tie-in coverage ("Moon Knight - Daredevil Devils Reign Complete Story PT2") already
  narrates this one-shot's story.

Lesson: for step-2e, LESSER-KNOWN quiet/detour issues inside a run (not the famous
"iconic moment" issues) are the ones still likely to be clean — e.g. Superman (2016) #39
"Goodnight Moon" (an emotional standalone that never became a "moment"/meme) and Moon
Knight (2021) #9 "Stranger" (a mid-run horror one-off, not a headline arc) were both
verified NO_NARRATION. Prioritize CBR-acclaimed but non-headline single issues over
Wikipedia-famous "iconic" ones.
